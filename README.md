# فروشگاه عمده‌فروشی سبزی

پروژه با Django اجرا می‌شود و برای اجرا به Node.js نیاز ندارد.

## اجرا در Windows

از PowerShell و ریشه پروژه:

    cd D:\shopsite
    .\.venv\Scripts\Activate.ps1
    python manage.py migrate
    python manage.py createsuperuser
    python manage.py sync_chortke_products
    python manage.py runserver 127.0.0.1:8000

سایت: http://127.0.0.1:8000/  
پنل اختصاصی: http://127.0.0.1:8000/panel/  
مدیریت ویدیوی صفحه اصلی در پنل، بخش «تنظیمات سایت» است. فایل‌های MP4، WebM و MOV تا ۲۵۰ مگابایت پذیرفته می‌شوند.

ثبت‌نام فقط نام، نام خانوادگی و شماره موبایل را می‌گیرد. نام کاربری برابر شماره موبایل است و رمز اولیه هم شماره موبایل است؛ مشتری پس از ورود می‌تواند رمز را از «تغییر رمز عبور» عوض کند. برای دیدن قیمت‌ها حساب باید در پنل تأیید شود.

قیمت‌ها با رقم فارسی و جداکننده هزارگان نمایش داده می‌شوند. موجودی در سایت نمایش داده نمی‌شود.

## چرتکه

توکن دسترسی در CHORTKE_ACCESS_TOKEN داخل فایل .env تنظیم می‌شود. نام، قیمت، عکس و دسته‌بندی از POST /v2/products/list دریافت می‌شوند. این endpoint در پاسخ واقعی فیلد موجودی ندارد؛ بنابراین همگام‌سازی موجودی خودکار ممکن نیست تا چرتکه endpoint مجاز موجودی در اختیار بگذارد. endpointهای مختص Didar از این پروژه استفاده نمی‌شوند.

همگام‌سازی دستی: python manage.py sync_chortke_products

## جست‌وجوی پیشرفته و تصاویر کالا

جست‌وجوی کاتالوگ، API و ربات از ترکیب تطبیق املایی (از جمله جابه‌جایی حروف)، یکسان‌سازی حروف و ارقام فارسی/عربی، کد کالا و بردار معنایی عنوان، دسته و توضیح استفاده می‌کند. کالاهای پنهان برای مشتری برگردانده نمی‌شوند و مجوز نمایش قیمت همچنان برقرار است.

کلید GapGPT را در تنظیمات پنل ثبت کنید. مدل پیش‌فرض بردارسازی text-embedding-3-small است و با SEARCH_EMBEDDING_MODEL قابل تغییر است. بردارها در دیتابیس ذخیره می‌شوند؛ فقط متن کالاهای جدید یا تغییرکرده دوباره ارسال می‌شود. بردار پرسش‌ها ۳۰ دقیقه کش می‌شود. در قطع سرویس، جست‌وجوی املایی فعال می‌ماند. بردارسازی هزینه سرویس دارد و متن کالاها به GapGPT ارسال می‌شود.

    python -m pip install -r requirements.txt
    python manage.py migrate
    python manage.py rebuild_product_search

بازسازی کامل اختیاری: python manage.py rebuild_product_search --force

هر همگام‌سازی چرتکه تصاویر را دوباره دانلود، با حداکثر اندازه ۹۶۰ پیکسل به WebP تبدیل و با آدرس تازه ذخیره می‌کند. پس از ثبت موفق داده‌ها، تصاویر نسل قبلی در media/product-images حذف و کش سرور پاک می‌شود. در خطای ثبت داده‌ها، تصاویر قبلی حفظ می‌شوند. عکس ناموجود یا دانلود ناموفق در بروزرسانی موفق تصویر قبلی را نگه نمی‌دارد؛ هشدار در پنل نمایش داده می‌شود. لوگو و ویدئو حذف نمی‌شوند. نسخه اصلی عکس روی سرور چرتکه تغییر نمی‌کند. در استقرار، مسیر MEDIA_URL را از MEDIA_ROOT سرو کنید و به فرایند Django اجازه نوشتن و حذف در آن بدهید.

برای تبدیل تصاویر فعلی بدون دریافت دوباره اطلاعات چرتکه:

    python manage.py optimize_product_images

این فرمان تصاویر فعلی محصولات را جایگزین و نسل قبلی تصاویر مدیریت‌شده را حذف می‌کند.


## قابلیت‌های مدیریت محتوا و همگام‌سازی

- «همگام‌سازی چرتکه» در یک فرایند پایتون جدا اجرا می‌شود. پنجرهٔ پیشرفت، دریافت کالا، آماده‌سازی تصاویر، ذخیره و بردارسازی را نشان می‌دهد. بستن پنجره کار را متوقف نمی‌کند. وضعیت و خطای تصاویر در «گزارش همگام‌سازی» قابل مشاهده است. محیط اجرا باید اجازهٔ ایجاد فرایند پایتون را داشته باشد.
- در «محصولات»، دکمهٔ «توضیحات / هوش مصنوعی» پیش‌نویس قابل ویرایش می‌سازد. کلید و مدل از تنظیمات سایت خوانده می‌شوند. ذخیرهٔ متن با دکمهٔ جدا انجام می‌شود و توضیحات اختصاصی در همگام‌سازی بعدی حفظ می‌شوند. بردار متن تغییرکرده در همگام‌سازی بعدی ساخته می‌شود.
- «استوری روزانه» هنگام مراجعه، تا ۵ کالای فعال و قابل نمایش دارای عکس را برای تاریخ جاری انتخاب و ثبت می‌کند. انتخاب همان روز ثابت است؛ در روز بعد انتخاب تازه ساخته می‌شود. خروجی هر استوری PNG عمودی ۱۰۸۰×۱۹۲۰ با لوگو و اطلاعات تماس است. نمایش قیمت اختیاری است. برای انتشار، فایل را دانلود و در نرم‌افزار دلخواه بارگذاری کنید.
- «گفتگوهای مشتریان» دکمهٔ حذف کامل همراه تأیید دارد؛ آمار مصرف تصویر مشتریان حفظ می‌شود.
- جست‌وجوی کاتالوگ پس از ۵۰۰ میلی‌ثانیه توقف تایپ، نتایج را بدون اینتر به‌روز می‌کند.


## پشتیبانی و تم مدیریت

- اپ مستقل پشتیبانی در store/support قرار دارد. دکمه شناور سایت به /support/ می‌رود؛ ورود لازم است ولی تأیید مشتری برای درخواست پشتیبانی لازم نیست. هر مشتری فقط گفتگوهای خودش را می‌بیند. همه کاربران is_staff از «پشتیبانی مشتریان» در /panel/support/ پاسخ می‌دهند، گفتگو را می‌بندند یا پیام و کل گفتگو را با تأیید حذف می‌کنند. پیام‌ها در دیتابیس ذخیره و هر ۴ ثانیه تازه می‌شوند؛ آرشیو قدیمی با دکمه «نمایش پیام‌های قدیمی‌تر» در دسترس است.
- عکس نمایش داده‌شده از display_image_url خوانده می‌شود: عکس اصلی محصول و در نبود آن، عکس پیش‌فرض قطعات خودرو.
- ساخت توضیحات از همان تحقیق وب استفاده می‌کند؛ منابع همراه پیش‌نویس نشان داده و پس از ذخیره نگهداری می‌شوند. اگر جستجوی واقعی یا منبع در دسترس نباشد، سیستم آن را ساخت متن با جستجوی موفق وانمود نمی‌کند.
- کنترل «تاریک / روشن» فقط در پنل مدیریت فعال است و انتخاب در مرورگر ذخیره می‌شود. تم عمومی سایت تغییر نمی‌کند.
- اجرای پروژه مانند قبل است: python manage.py migrate و python manage.py runserver. برای سرور تولید، پوشه رسانه‌ها باید سرو شود و ایجاد فرایند پایتون برای همگام‌سازی مجاز باشد.
